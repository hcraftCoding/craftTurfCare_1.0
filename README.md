# Craft Turf Care

A mock landscape company website with a client CRM built as a frontend web project.

## Features
- 7-page website (Home, Services, About, Gallery, Contact, Login, CRM)
- Quote request form that creates CRM leads automatically
- Client management system (add, edit, delete, filter)
- Preloaded mock client data
- JS-based login with intentional security vulnerability (documented below)

## Tech Stack
- HTML
- CSS
- JavaScript
- localStorage (client data persistence)

## Security Note
The CRM login uses a hardcoded JavaScript password. This is an intentional 
vulnerability included for educational demonstration. In a production system, 
authentication would be handled server-side.

## Planned Features
- Python backend (Flask)
- Real database integration
- Proper authentication
